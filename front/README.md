# LimpaCity Web

Interface React com TypeScript, Vite e Tailwind CSS.

## Configuração

Copie `.env.example` para `.env`. `VITE_API_URL` indica a URL base da API e, localmente, usa `http://localhost:8080`.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
```

Tailwind CSS é processado pelo plugin oficial do Vite e importado em `src/styles.css`.
